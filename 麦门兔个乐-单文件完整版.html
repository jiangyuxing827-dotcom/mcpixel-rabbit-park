作品说明

《麦门兔个乐》是一款融合 AI、像素艺术、趣味点餐与休闲游戏的互动应用。

我想让点餐这件普通的小事变得更有意思。所以设计了一只豆豆眼兔子，打造了一个可以自由探索的麦门像素世界。

在这里，你可以 DIY 汉堡、无限叠加肉饼、自由搭配套餐；也可以体验麦当劳打工模拟、消消乐、切切乐、贪吃蛇、麦门人生和16型 MBTI 人格测试。不同游戏还会解锁专属皮肤、成就徽章和节日幸运物。

项目尝试结合麦当劳 MCP 服务与 AI 辅助开发，将实际餐饮信息、游戏互动和数字收藏连接起来，让点餐不再只是完成一次购买，而是一次有趣的探索。

毕竟，人生已经够忙了，点个麦当劳总得图个乐吧！

如何接入 mcd-mcp 实时数据？
  1. 打开 open.mcd.cn/mcp，手机号登录后在右上角「控制台」申请 MCP Token（限中国大陆、非商业用途）。
  2. 在 WorkBuddy「连接器 → 自定义连接器 → 配置 MCP」中粘贴配置（Token 只放本地，勿外传）：
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": { "Authorization": "Bearer YOUR_MCP_TOKEN" }
    }
  }
}
  1. 把官方菜单数据写入本项目的 data/menu.json：在 WorkBuddy 中启用 mcd-mcp 连接器后让我抓取，或运行 python3 fetch_menu.py（读取环境变量 MCD_MCP_TOKEN，依次调用 query-meals / list-nutrition-foods / query-store-coupons / campaign-calendar）。刷新页面即完成替换，字段映射见 MCP_INTEGRATION.md。

关于

McPixel 是 16-bit 像素风点餐概念原型「麦门兔个乐」，与麦当劳无官方关联。徽章、皮肤与动画均为本地演示，数据仅保存在浏览器 localStorage。

McPixel · 概念原型演示 — 未连接官方点餐渠道，不会产生真实订单；真实价格、优惠与库存以门店和官方渠道为准。
使用麦当劳 MCP 服务须遵守其《使用条款》与《MCP 服务规则》，仅限中国大陆地区（不含港澳台）、非商业用途。
